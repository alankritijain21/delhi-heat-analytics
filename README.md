# Delhi Heat Crisis Dashboard 🌡️

End-to-end data analytics project analyzing Delhi's summer
heat patterns using Python, Pandas, SQL, Matplotlib, Seaborn
and Power BI — built on real IMD climate data.

## Key Findings

| Metric | Value |
|--------|-------|
| Period analyzed | 2013–2016 + 1990–2022 (long-term) |
| Total days analyzed | 1,462 |
| Overall average temp | 25.5°C |
| Summer average (Apr–Jun) | 32.2°C |
| Heatwave days (mean ≥35°C) | 92 days — 6.3% of all days |
| Hottest day recorded | 25 May 2013 — 38.71°C |
| Longest heatwave streak | 11 consecutive days (May 2016) |
| Hottest month | June (avg 33.73°C) |
| Long-term warming | +0.40°C per decade since 1990 |
| Heatwave days increasing | +1.29°C warmer vs 1990 |
